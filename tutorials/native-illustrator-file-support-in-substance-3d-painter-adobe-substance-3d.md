### Importing the Illustrator file [1:21]
**Transcript (timestamped):**
[1:21] Save your Illustrator document normally. Then you need only drag and drop this file into Painter.
[1:29] Dropping it into the 3D view will place it in warp projection mode as a material.
[1:35] Dropping it in the 2D view will place it in UV mode as a material.
[1:40] And dropping it in your layer stack will place it in UV mode in a specified channel.
[1:46] In this case I choose base color.
[1:49] You can now place it where you want in your stack, scale it and position it. In most cases you will want to not have it repeat.


### Changing artboards [2:01]
**Transcript (timestamped):**
[2:01] In the layer options you will see that you have some file type specific settings.
[2:06] You will find all of your artboards here and you can switch between them.
[2:11] This is a great way to work as you can essentially create a whole design by using just one Illustrator document and then swapping the artboards.
[2:20] Illustrator files contain vector graphics which are resolution independent and can scale up without losing quality.
[2:28] The default option here is Auto and this will set the graphics at the resolution of your Painter project.
[2:34] But you can also use other resolutions, cropping settings and non-square aspect ratios.
[2:40] Scope will let you select which objects to use from your Illustrator artboards.
[2:46] In this example I have a layer with a group which itself contains several other groups and elements.
[2:53] This can all be viewed and selected within the scope window and you can even have thumbnails.
[3:00] Another great thing about this workflow is that you can continue to work non-destructively on your Illustrator graphics in Painter by applying to them filters and other effects.


### Adding additional filters & effects [3:02]
